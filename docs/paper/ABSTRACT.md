# Abstract (re-scoped, submission / preprint, ~210 words)

Activation-delta probes — linear classifiers over the difference between a frozen LLM's representation with and without a user turn — have been proposed for detecting prompt-injection and jailbreak attempts. We pre-registered (OSF `ep6ab`, DOI 10.17605/OSF.IO/EP6AB) a leak-free evaluation of whether such a probe detects an attempted *override* of a system instruction, with a primary focus on benign imperative-constraint false positives (over-defense), using a frozen Qwen3.5-4B and a two-pass delta (last-token, layers {3,6,12}), trained on two attack families and tested on eight held-out families, five held-out system prompts, and held-out constraint types.

The confirmatory result is **mixed/negative**. The primary hypothesis held on our data (benign-constraint FPR 0.018, CI [0.000, 0.054] at 0.90 override recall) and replicated on PIDS-Bench (mean FPR 0.018). But cross-family generalization missed the pre-registered bar (mean per-family AUROC 0.877, CI [0.828, 0.918]); the discriminant control was refuted, with a 2×2 decomposition showing a **source/style interaction** (harm main effect ≈ −0.03, interaction −0.79) rather than harm-tracking; and a **TF-IDF baseline on raw text outperformed the delta** (0.929 vs 0.895), so by our own rule the internal-state delta adds no substantial value over surface features. A layer-wise sweep found no depth beating the text baseline (best 0.915 at L20), with obfuscation irreducibly weak. Per the preregistration we re-scope the construct: this is a **boundary study** showing activation-delta probes are largely surface-redundant and source-confounded for prompt-injection, not a working override detector.

**Keywords:** prompt injection, activation deltas, linear probing, over-defense, TF-IDF baseline, preregistration, negative result.
