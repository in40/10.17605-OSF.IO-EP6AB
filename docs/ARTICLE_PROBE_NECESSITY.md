# SymFw — «Нужен ли проб?» (материал для статьи)

## Уникальный вклад проба
Проб находит **различающее направление** в многомерной дельте. Без него `DELTA`
некуда пороговать: `delta_norm`/`drift` не дискриминантны (тон в обработке
данных), а «ось перехвата» в реальном hidden-пространстве заранее неизвестна
(нельзя захардкодить «координата 4213 = инъекция»). Найти = выучить.

## Лестница отказов от проба
- **Без обучаемого** → порог на `norm`/`drift` → не работает.
- **Только маркеры/строки** → обход перефразом + FP на tricky («забудь про форматирование»).
- **Только post-hoc verifier** (NLI на ответ) → нет защиты **до** генерации, медленнее, ловит плохой ответ, а не смену состояния.
- **Unsupervised anomaly** (Mahalanobis к чистым) → нет разметки инъекций, но всё равно обучаемая модель.
- **Готовое RepE-направление** (refusal/override) → без обучения, но refusal ≠ injection, перенос под вопросом.

Вывод: какой-то выученный компонент нужен, чтобы разделять «обработку данных» и
«перехват» до генерации.

## Минимальный проб = одна строка
`w = mean(DELTA_injection) − mean(DELTA_clean)` (difference-in-means /
contrastive direction), `score = cos(DELTA, w)`. Закрытая форма, без итераций и
библиотек. «Проб» ≠ тяжёлая ML-машина — может быть просто вектором-направлением.

## Сущностен vs лишний — зависит от threat model
- **Только наглая инъекция** («ignore previous instructions») → маркеры +
  post-hoc verifier хватает; проб = overkill.
- **Коварная indirect** (отравлённый RAG-документ выглядит легитимно, дельта
  большая, но НЕ по оси перехвата у tricky) → проб сущностен.

Проб живёт ради **сложной середины**: tricky-легитимный с большой дельтой vs
инъекция с большой дельтой.

## Дельта опциональна, проб — нагруженная деталь
Проб можно вешать и на полный hidden state (стандартные «hidden detectives»
jailbreak-пробы). Дельта — лишь preprocessing, убирающий вклад системного
промпта и облегчающий пробу задачу.

## Фрейм для статьи
Вопрос не «проб или нет», а **«нужно ли ловить коварную середину до
генерации»**. Да → проб (начать с difference-in-means). Нет (только наглые
атаки) → маркеры + внешний verifier.
